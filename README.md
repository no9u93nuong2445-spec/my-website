# 心动训练营 V2.21

完全离线的恋爱沟通训练系统，包含 **6 名独立性格角色、45 个实战关卡、5 个连续真实场景**、教练/沉浸双模式、隐藏挑战、整局回放、逐句标色复盘、自由练习、知识课程、错题专项、数据备份和本地密码锁。

## V2.21 核心升级

### 1. 整局对话回放

从 V2.21 起，新完成的训练会在本机历史记录中保存：

- 用户每一句原文；
- 角色对应回复；
- 单句分数和表现等级；
- 系统识别的动作、对象和上下文；
- 主要问题或做得好的地方；
- 更好的替代表达和下一步动作。

旧版本只保存汇总分数，没有保存逐句原文，因此不会伪造旧记录的回放。

### 2. 逐句标色

- **绿色**：表达自然有效；
- **黄色**：可以继续，但仍有明确优化空间；
- **红色**：出现施压、脑补关系、问题过密、明显越界或低质量表达；
- **蓝色边框**：本局关键转折，包括最佳句、最低分句、边界处理、压力上升或分数大幅变化。

### 3. 整局结论

复盘会汇总最佳轮次、最低轮次、无效追问、边界动作、最高频问题和下一局唯一训练重点。避免一次列出十个问题，让用户能够真正改掉一个稳定习惯。

### 4. 历史记录再次打开

在“报告 → 最近训练历史”中，V2.21 之后的新训练会出现“逐句复盘”按钮。删除单局历史时，对应回放也会一起删除。

- `app.js`：Jekyll 组合入口；
- `fragments/app-01.txt` 到 `app-16.txt`：基础对话引擎；
- `fragments/app-v219-overlay.txt`：真人感角色与训练模式；
- `fragments/app-v220-overlay.txt`：连续真实场景；
- `fragments/app-v221-overlay.txt`：整局回放和逐句复盘；
- `.github/scripts/build_v221_app.py`：生成完整 V2.21 JavaScript；
- `.github/scripts/dialogue_v221_harness.js`：27 项回归测试；
- `app/`：与网页版同源的 Android WebView 工程。
